# 你付的 AI 账单里，有多少是"想多了"？
——从过度思考看 token 经济里的委托代理问题

## 一、想对之后，它还在想
你让 AI 解一道难题，它"思考"了一分钟才给出答案。假如它在第 20 秒就已经想对了，后面那 40 秒照样要你付钱，最后的答案还可能被它想错。

这不是假设。中科院等机构最近发表的 [OTBench 研究](https://arxiv.org/abs/2610.13570)，把 6 个推理模型的思考过程切成小段，每想到一处就停下来让它作答。结果发现，平均约 64% 的思考 token 是在正确率已经见顶之后才生成的。把思考进行到底，正确率反而比峰值平均低 9 个百分点。

## 二、浪费压在账单最贵的地方
只看这一个数字，好像只是技术上的效率问题。再放上另一组数据，问题就变了。

一份 [2026 年 AI API 价格指数](https://aitokensai.com/benchmark/price-index-2026/) 按真实使用时的 token 配比重新计算了 219 个模型的价格。结论是在智能体负载下，输出 token 约占账单的 92%。推理模型的思考 token 恰好按输出计费。

做个粗略的示意估算：92% × 64% ≈ 59%。

在极端假设下，用户账单里可能有接近六成，是在为"想对之后还在想"付钱。这个数字不能当精确结论用：它取决于思考 token 在输出里占多大比例，论文测的也是开源模型做题，而不是商用智能体。但量级本身已经值得警惕：过度思考的成本，正好落在账单里最贵、占比最大的那一块。

## 三、经济学早就见过这种结构
### 1. 委托代理：谁决定，谁付钱
用户是委托人，想要的是正确答案。厂商是代理人，决定模型想多久，同时按 token 收费。在 Jensen 和 Meckling 的框架里，只要代理人的收益和委托人的目标不一致，就会产生代理成本。这里的不一致很直接：多想一步，厂商多收一份钱，用户多付一份钱，答案却未必更好。

### 2. 信息不对称："信任品"式的计费
经济学把一类商品叫作信任品（credence goods）：买方连事后都难以判断自己买到的服务值不值，比如看病和修车。Dulleck 和 Kerschbamer 指出，这类市场容易出现"过度服务"和"过度收费"。

隐藏的思考过程正是这种结构。用户看不到模型在哪一步已经想对了，也无法核对那几千个思考 token 是否必要。计费单位是可观测的 token，真正有价值的东西却是不可观测的"恰到好处的思考"。

### 3. 道德风险与激励设计
如果按投入（token）付费，代理人就没有节约的动力；如果按产出（结果）付费，激励才会对齐。这正是 Holmström 关于激励合同的核心思想。OTBench 的另一个发现在这里很有意义：理想情况下，边想边判断何时停的策略只要约 14% 的 token 就能追平完整思考，而现有方法离这个上限还很远。技术上能省的空间很大，可在现行定价下，谁来推动这件事？

### 4. 市场力量：默认值就是定价权
价格指数还显示，同一厂商不同模型的价差可达约 456 倍。厂商通过默认推理强度和档位设计，实际上决定了用户最终付多少钱。在竞争充分的市场里，过度收费会被对手的低价挤出去；但当少数厂商掌握前沿模型、用户的转换成本又高时，这种"默认值定价"就可能接近反垄断法里讨论的剥削性滥用。

## 四、出路在哪里
- **计费透明**：单独列出思考 token 的数量和费用，让用户至少知道自己为哪部分付了钱。
- **用户掌握预算**：允许用户设定推理上限或推理强度，把"想多久"的决定权部分交还给委托人。
- **按结果定价**：在可验证的任务上（代码通过测试、题目答对）试行按结果收费，让激励和用户目标对齐。
- **监管视角**：消费者保护和算法透明度规则，可以把"隐藏推理的计费"纳入信息披露要求。

## 五、结语
AI 的下一场竞争，不只是谁想得更聪明，还有谁知道什么时候该停。经济学提醒我们，当做决定的人和付钱的人不是同一个人时，"停"这件事不会自动发生，它需要合同、透明度和竞争来推动。
