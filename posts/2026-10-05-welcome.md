# 你好，世界

欢迎来到我的个人博客。这是第一篇，用来说明这个站点的来由，以及我会在这里写些什么。

## 关于这个站

这里用来记录：

- 日常的小片段
- 一些想法和笔记
- 拍下的图片

文章用 **Markdown** 写成，图片放在 `images/` 目录。整个站点是纯静态的，没有任何后台，外网通过 GitHub Pages 访问。

## 一张示例图片

下面这张图引用自 `images/welcome-cover.svg`，是个用 SVG 写的渐变占位图。你可以在文章里这样引用图片：

```markdown
![图片说明](images/welcome-cover.svg)
```

![渐变占位图](images/welcome-cover.svg)

## 排版示例

正文里可以有 **加粗**、*斜体*、`行内代码`，以及引用块：

> 哪怕只是流水账，记录下来也是好的。

也可以有列表、表格、分割线，比如：

| 时间 | 心情 |
| --- | --- |
| 早上 | 平静 |
| 下午 | 想念 |
